## 📌 Sobre o Projeto

O sistema ILPF é uma estratégia de produção sustentável que integra atividades agrícolas, pecuárias e florestais em uma mesma área. Este projeto foi criado com o objetivo de:
* [Objetivo 1, ex: Facilitar a visualização de dados climáticos e do solo]
* [Objetivo 2, ex: Apresentar relatórios de produtividade e sustentabilidade]
* [Objetivo 3, ex: Servir como ferramenta de suporte para produtores rurais]

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas e tecnologias:

* **HTML5 / CSS3** - Estruturação e estilização da interface.
* **JavaScript** - Dinamismo e manipulação de dados [ou bibliotecas como Leaflet.js / Chart.js se houver mapas/gráficos].
* **GitHub Pages** - Hospedagem rápida e gratuita diretamente do repositório.
